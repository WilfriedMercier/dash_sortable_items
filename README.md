# Dash Sortable Items
A set of Dash components built with React that provide an interface to generate sortable items within a group.


## Running `usage.py` 

Examples can be found in the `usage.py`. In order to run them, first setup a virtual environment and activate it with

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The examples use [dash-mantine-components](https://www.dash-mantine-components.com/) and [dash-iconify](https://www.dash-mantine-components.com/dash-iconify) but these libraries are not mandatory to use this one.
